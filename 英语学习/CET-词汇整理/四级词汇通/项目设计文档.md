> 本文档用于记录项目完整设计与架构,方便后续开发时快速理解。最后更新:2026-08-30

## 一、项目概览

**英语词汇通**(原名「四级词汇通」,现支持 6 个学段词库) 是一个纯前端的多学段背单词应用,零后端、零构建、双击即用。

| 项 | 说明 |
| --- | --- |
| 项目路径 | `D:\英语学习\CET-词汇整理\四级词汇通\` |
| 词汇数据 | 6 个词库可切换：四级(内置4543) + 小学/初中/高中/六级（`lib-sources\*.json` 生成，见 `vocab-libs.js`） |
| 技术栈 | 原生 HTML + CSS + JavaScript(无框架、无依赖) |
| 数据存储 | 浏览器 `localStorage` |
| 使用方式 | 电脑本地服务器版 + 手机 PWA(添加到主屏幕,离线可用) + 手机离线单文件版 |

> 📌 **释义已精简(2026-08-10)**:原释义由多词典合并而来、近义冗杂(平均 16.3 字/词),已精简为保留核心义(平均 9.9 字/词,压缩约 39%),统一合并 vt./vi. 为 v.。精简前数据见 `文件_去重合并版_精简前备份.txt`。

### 3.2 state 结构 (`cet4_study_state_v1`)

```js
state = {
  settings: {
    dailyNew: 20, dailyReview: 30, autoSpeak: true, lib: 'cet4',
    // 自由拼写配置(范围+数量+自选词单;'custom' 范围用 spellWords,不受数量限制)
    spellScope: 'all', spellCount: 20, spellWords: [],
    // 听写配置(范围/数量/作答方式judge判分|listen自查|auto自动轮播/自选词单/轮间停顿秒/语速/顺序/循环)
    dictScope: 'all', dictCount: 10, dictMode: 'judge',
    dictWords: [],
    dictPause: 1, dictRate: 0.9, dictOrder: 'random', dictLoop: false,
    voiceSrc: 'edge',                         // 音源:edge Edge朗读(默认) / tts 设备TTS(旧档 onlineVoice/三态 voiceSrc 迁移)
    ttsEngVoiceName: '', ttsZhVoiceName: '',  // 设备TTS声音(空=自动优选),兜底层用
    edgeVoiceEn: 'en-US-AriaNeural', edgeVoiceZh: 'zh-CN-XiaoxiaoNeural',  // Edge朗读音色
  },
  libs: {                                           // 学习进度按词库隔离
    cet4: { words: { ... } },                       // libs[libKey].words = 单词学习记录
  },
  words: {                                          // 每个单词的学习记录(旧版字段,启动时迁移到 libs.cet4.words)
    [word]: {
      stage: 0~5,        // 0新词, 1-4复习级, 5已掌握(完全记住)
      due: 时间戳,        // 下次复习时间(仅 stage>=1 用;已掌握为 Infinity)
      right: 累计答对,     // 注意:这是"累计答对次数",不是会话内计数
      wrong: 累计答错,
      inBook: 是否在生词本,
      created: 首次学习时间戳,
    }
  },
  today: 'Tue Aug 04 2026',          // 当日字符串,用于跨天重置
  learnedToday: [],                  // 今日新学(跨天清空)
  reviewedToday: [],                 // 今日复习(跨天清空)
  history: {                          // 每日学习记录(持久保留);条目为 [词库key, 单词]
    '2026-08-04': { learned: [], reviewed: [], wrongs: [] }
  },
}

// 每日目标
goalInfo() = {
  target,        // settings.dailyNew
  learned,       // learnedToday.length
  remaining,     // max(0, target - learned)
  done,          // learned >= target
  allDone,       // done 且无未学单词(全部学完)
  dueToday,      // 今日到期待复习数
  reviewedToday, // reviewedToday.length
}
```

> **学习记录条目带词库归属(2026-08-30)**:条目为 `[词库key, 单词]`,渲染时显示词库小标签、释义按 `defInLib(归属词库)` 查——修复跨词库单词在学习记录里显示空释义的问题。`normHistEntry()` 兼容旧版纯字符串条目(按词库包含关系归属,多词库重叠词优先当前词库);导入进度同时接受新旧两种条目格式。

### 3.3 会话快照结构 (`cet4_session_snapshot_v1`)

断点续学用。每个答题动作后保存,完成/放弃时清除。

```js
snapshot = {
  mode: 'study' | 'review',
  queue: [单词...],          // 本次全部单词
  pending: [单词...],        // 待识别队列(新词,答对一次即过)
  retries: [单词...],        // 答错待重记队列(须答对3次)
  sinceRetry: 0,             // 距上次穿插错词的间隔(每3个新词插1个错词)
  idx: 0,
  correct: 0, wrong: 0,      // 会话内计数
  spellOn: false,            // 是否进入拼写阶段
  phase: 'recognize'|'spell'|'spellAsk',
  records: [[word, { errors, corrects, spellCorrects, done }]],
}
```

## 四、核心算法

### 4.1 艾宾浩斯复习间隔

```js
const INTERVALS = [1, 2, 4, 7, 15];   // 天
const STAGE_MASTERED = 5;
```

- 复习**答对一次升 1 级**,下次复习间隔按 `INTERVALS[stage-1]` 天
- 复习**答错一次降 2 级**,但**最低降到 1 级**(`Math.max(1, stage-2)`)——stage 0 会被 `dueWords()` 排除,若降到 0 则「10 分钟后当天再复习」永远不触发
- 升到 `stage >= 5` 判定「完全记住」,`due = Infinity`,不再出现在复习队列
- 复习答错后 `due` 设为 10 分钟后(当天可再复习)

### 4.2 学习/复习会话三段式流程(学习与复习逻辑一致)

```
第1阶段·识别:
  四选一固定英译汉（看单词选释义），学习与复习一致
  汉译英（看释义写单词）的考察由第 3 阶段拼写承担，识别阶段不混题型
  答对(新词1次,错词3次达标) → 移除队列
  答错/点不会 → 不卡住,进 retries 错词池,显示反馈后刷新下一个
  穿插规则:每学3个新词穿插重现1个错词;多个错词按序轮转交替,避免同一错词连续出现

第2阶段·拼写询问(可选):
  识别全部完成后,弹窗问「要不要练习拼写?」
  开始拼写 或 跳过直接完成(用户可拒绝)

第3阶段·拼写:
  看释义输入英文单词,连续拼对2次(SPELL_REQUIRED)才算完成
  拼错不卡住:先出下一个词,该词进拼写错词池(spellRetries),稍后穿插重现
  穿插规则与识别阶段一致:每拼3个词穿插重现1个拼写错词;多个错词轮转交替
  拼错重置该词连续正确数(spellCorrects)
```

### 4.3 答错处理

| 位置 | 处理 |
| --- | --- |
| 识别题答错 | 进 retries 重记池、累计 `wrong`、**不强制进生词本**(用户点按钮自选)、写回 state |
| 点「不会」 | 同答错处理,显示答案 |
| 拼写答错 | 重置拼写连续数、进拼写错词池稍后穿插重现、累计 `wrong`、写回 state,反馈含正确拼写+释义 |
| 复习答错 | 额外触发艾宾浩斯降级 |

### 4.4 答错反馈(双语提示)

答错后反馈区显示:
```
❌ 答错了，稍后会再考你
  hello   /   n. 你好       ← 正确答案对照(wrong-pair)
  「n. 你好」的英语是：hello    ← 选错选项的翻译提示(wrong-hint)
[📌 加入生词本]  [下一个 →]
```

- **英译汉**选错中文 → 反查词库提示「X 的英语是:…」(`app.js` 的 `reverseDefToWord`,优先跳过当前词)
- 点「不会」无选错选项时,不显示该行
- **其余错误选项可点看**(2026-08-30):答错反馈里把另外 2 个干扰项渲染成可点标签(`.def-chip`,点「不会」时 3 个干扰项全部可点),点击展开「该释义的英语是:xxx」(`toggleDefChip`),再点收起;`pickDistractors` 保证干扰项释义互不相同,反查无歧义

### 4.5 出题、干扰项与发音

- **干扰项质量**(`pickDistractors`):优先同词性(按释义前缀 adj./n./v. 等判定)、词长相近;排除与答案**同释义**的词,且干扰项**彼此释义也互不相同**(词库有 74 组同释义词,如 cozy/comfortable,不过滤会出重复选项)
- **题型**:`makeQuestion(word, reverse)`,reverse=true 出汉译英(题干=释义,选项=单词)。识别阶段固定不传 reverse;该参数当前未启用,作为出题器能力保留
- **发音**(2026-08-30 定稿为两层引擎,音源二选 `settings.voiceSrc` = edge/tts;**有道/百度"在线真人"音源已整体移除**——用户定档只用 Edge,相关代码/口音设置/SW 音频缓存均已删除):
  - **① Edge 朗读(默认音源,男女音色自选)**:微软 `wss://speech.platform.bing.com` WebSocket 直连,`Sec-MS-GEC` token 走查询参数(浏览器 WS 设不了自定义头)。**只在 Edge 浏览器可用**——服务端校验浏览器真实 UA(须含 `Edg/`/`EdgA/`/`EdgiOS/` 且主版本 ≥135),网页伪造不了 UA,`isEdgeBrowser()` 判非 Edge 环境直接禁用该音源。token 用 **float64 运算**生成(FILETIME 100ns 刻度向下取整 5 分钟 + TrustedClientToken 后 SHA-256 大写,`edgeGecTicks`);**必须保持 float 语义**——ticks≈1.3e17 超出 2^53,浮点舍入后的值才是服务端期望值,BigInt 精确值反而 403(实测踩坑)。产物 MP3 Blob → `<audio>` 播放。**两级缓存**:内存 LRU(`edgeBlobCache`,200 条,本会话)+ **IndexedDB 永久缓存**(`cet4-edge-tts` 库,存 Blob,跨会话离线可用,失败静默降级纯内存);`edgeSynthesize` 带**在途去重**(预取+立即播同文本只发一条连接)。**预取**:`prefetchUpcomingAudio()` 在呈现新词时(识别/拼写/听写/自由拼写)把后面 4 个词的音频提前合成进缓存(串行队列 `edgePrefetchChain`),第一次听到也不等网络。音色表 `EDGE_VOICES`(16 个):英语 10 个(美/英音)、普通话 6 个,按女声/男声分组显示中文名;设置存 `edgeVoiceEn/edgeVoiceZh`。CSP `connect-src` 放行 `wss://speech.platform.bing.com`
  - **② 设备TTS 兜底**:`speechSynthesis`,Edge 失败/关闭时降级。设置页「发音」卡可选英语/普通话声音(`ttsEngVoiceName`/`ttsZhVoiceName`,空=自动优选,逻辑 `pickBestTTSVoice`),中文只收 zh-CN;下拉按女声/男声/其他分组显示中文名(`voiceMeta`);安卓 voices 异步加载带 5 秒轮询兜底,列表空显示提示(已注明与在线发音无关);iOS 手势解锁 TTS、静音 wav 解锁 `<audio>`;只在播报中才 `cancel()`,speak 后 250ms 未开始重试一次
  - 播放链统一:`speakWord`/`speakDictText` 按 ①→② 顺序,`speakEpoch` 代际号保证停止播报后旧文本不从下层冒声;英译汉出题自动朗读(可关);点 🔊 重读。所有发声途径都没有的环境才隐藏 🔊/听写入口(`canSpeakHere()`)
- **桌面快捷键**:识别阶段数字键 1-4 选选项;出反馈后 Enter 进下一个;拼写阶段 Enter 提交/前进

### 4.6 每日目标

首页「今日目标」卡片:新学进度条(`learned/target`)、复习到期数、完成状态。

- **目标 = `settings.dailyNew`**(设置页可调)
- **达成判定**:`learnedToday.length >= dailyNew`;若同时无未学单词 → 显示「全部学完🏆」
- **阻断**:今日新学达成后,点「学习新词」进入 `goalDoneHtml()` 完成页,不再开新会话;可去设置调高目标继续
- **提交点**:新词在**识别阶段答对达标**即 `learnWord(word)` 记为已学(计入 `learnedToday`);拼写阶段是纯练习,不再重复提交
- **隔天复习**:`learnWord` 设 `due = 现在 + 1 天`,保证新词至少隔一天才进入复习队列
- **复习进度条**:首页目标卡复习行有独立进度条(`reviewedToday / settings.dailyReview`),达标显示「复习目标达成 ✓」
- **复习空守卫**:`startReview()` 无到期词时显示「暂无到期复习」提示页,不创建空会话

### 4.7 巧记(memo)

- **数据**:`vocab-extra.js` 的 `VOCAB_EXTRA = { 单词: "巧记文本" }`;`app.js` 的 `EXTRA_MAP` + `memoOf(word)` 查询,无数据返回空串(数据缺失时功能静默降级)
- **覆盖**:只配难词(2140 个)——词长≥7、易混短词种子清单,排除常见复合词(birthday/notebook 等)与 -er/-or 简单动作者名词;简单词无巧记
- **展示**:
  - 识别/拼写答错反馈:自动显示 💡 巧记行(最需要记忆钩子的时刻)
  - 生词本、掌握情况列表:有巧记的词行尾显示 💡 按钮,点击展开/收起
  - 学习卡片上**不**常驻显示(避免干扰识别答题)
- **再生成**:改巧记直接编辑 `vocab-extra-chunks/*.js` 后跑 `node build-extra.js`;`build-extra.js` 会按 `hard-words.json` 校验全覆盖、无空值、无超长(>45 字)

### 4.8 词库切换

- **注册**:`app.js` 的 `LIBS` = 内置四级(`vocab-data.js` 的 VOCAB,key=`cet4`) + `vocab-libs.js` 的 `VOCAB_LIBS`(primary/junior/senior/cet6);`LIB_WORD_SETS` 是各词库单词集合,导入进度时过滤用
- **切换**:`setLibrary(key)` 只改 `settings.lib` 并 `rebuildWordData()` 重建 `WORD_MAP/WORD_LIST`;UI 入口在**首页** hero 卡下方的词库 chip 行(`confirmSwitchLib`→弹窗→`doSwitchLib`,有进行中会话时提示会放弃并清快照);hero 角标、顶栏副标题、题卡右上角角标(CSS 变量 `--lib-badge`)都跟随当前词库
- **进度隔离**:学习记录存 `state.libs[libKey].words`(辅助函数 `curWords()`),各词库互不影响;**每日目标/学习记录(history)是全局的**,不随词库分开
- **旧档迁移**:`loadState()` 把旧版扁平 `state.words` 迁移为 `state.libs.cet4.words`
- **导入导出**:EXPORT_VERSION=2,v2 按词库合并;v1 旧进度文件当作四级词库导入;词库选择以本地为准
- **巧记跨库通用**:`memoOf()` 按单词查 `VOCAB_EXTRA`,其他词库查不到就静默无巧记
- **再生成**:改词库源 JSON 后跑 `node build-libs.js`;新增词库在 `build-libs.js` 的 LIBS 数组里加一行(key+文件名+名称)

### 4.9 PWA(像手机 App 一样使用)

- **安装方式**:手机浏览器访问应用网址 → 菜单「添加到主屏幕」→ 桌面生成独立图标,点开全屏无地址栏
- **入口选择**:index.html 直接作为 PWA 入口(多文件版在 http 下本就可用);手机单文件版保持不变,走 file:// 时 SW 注册自动跳过
- **离线**:`sw.js` 缓存优先,首次打开后全部资源入缓存,断网可用;断网时导航请求回落到缓存的 index.html
- **SW 生效条件**:**https 或 localhost**。GitHub Pages(https) 完全可用;`server.js` 的局域网 http 地址 SW 不会注册(浏览器安全限制),添加到主屏幕仍可用但无离线缓存
- **更新**:发布新版后把 `sw.js` 的 `CACHE_VER` 升一位**并同步改 pwa-register.js 里的 `sw.js?v=N` 参数**,再重新部署;缓存策略是 stale-while-revalidate(先回缓存保速度,后台静默更新),用户联网打开一次、下次打开即新版。**安装与同源后台刷新均带 `cache:'reload'` 绕过 HTTP 缓存**(v11,2026-08-30):Pages 给资源 10 分钟 max-age,曾导致部署窗口期把旧 index.html 装进新版本缓存,旧页面+新 JS 混版后旧内联 onclick 调不到已改名的函数(症状:设置页点击无反应)
- **推荐托管**:GitHub Pages——仓库设置里开启 Pages 后得到 `https://<用户名>.github.io/<仓库>/.../四级词汇通/index.html(目录名未改,文件名与应用名已改为英语词汇通)` 永久链接;手机首次访问安装,之后离线用,有更新时联网打开一次即可

### 4.10 断点续学
- 每个答题动作后 `saveSessionSnapshot()` 存快照(带归属日期 `day`)
- **2026-08-30 改**:首页不再显示"有未完成的学习"横幅(`updateResumeBanner/resumeSession/discardResume` 已删);未完成会话的状态静默保留**当天**,不做任何提示
- **跨天重置**:`loadSessionSnapshot()` 发现快照日期非当天即自动删除(第二天打开自动清掉,学习状态随 `learnedToday` 一起跨天重置)
- 切换词库时仍会提示"进行中的会话将被放弃"(`hasSnapshot()` 判断)
- 快照**不随**导出/导入同步(跨设备进行中会话不互通)

### 4.12 自由拼写(自定义拼写练习,2026-08-30)

- **入口**:首页「自由拼写」行动作 → `screen-spell`,先配置再开始:范围(全部/未学习/学习中/已掌握/生词本/**自选**,取词用 `app.js` 的 `wordsInScope`)+ 数量(**自定义输入**,−/输入框/+,限制 1 ~ 当前词库总词数,`setPracticeCount` 钳制);配置存 `settings.spellScope/spellCount`,记住上次选择
- **自选词单**(2026-08-30):范围含 `custom` 档,配置页「选定具体单词」进选词器(自由拼写/听写共用,`openWordPicker/renderWordPicker`)——搜索 + 按范围筛选 + 点行勾选,词单存 `settings.spellWords/dictWords`(按当前词库过滤生效,`practicePicked`,切词库后他库词自动忽略);自选范围**采用全部词单、不受数量限制**(`practicePool`);勾选就地更新行样式不整页重渲染(保住滚动位置)
- **批量选择**(2026-08-30):① **长按拖动连续选择**——长按一行 350ms 进入连续模式(该行先被设为反向状态),手指往下滑过哪些行就统一设成该状态(滑过已选的则连续取消),`attachPickerGestures` 用 pointer 事件 + `elementFromPoint` 命中行,长按期间 `touchmove` preventDefault 阻止页面滚动,松手结束(触发的那次 click 被吞掉不影响);② 底部「**全选**」把当前筛选/搜索结果全部写入词单,配合「清空」可整批重建
- **机制**:看释义输单词提交判分;答错不卡住直接跳过并显示反馈,错词进会话内重现池,**每过 3 个词穿插重现 1 个**(复用 `RETRY_INTERVAL` + `rotateSpellRetries`),重现时**答对 1 次即完成**(比复习拼写连对 2 次宽松)
- **纯练习**:`session.mode='spell'`、`phase='cspell'`(避开全局快捷键对复习拼写的接管);**不写学习状态**(stage/due/right/wrong 全不动,不计每日目标),答错反馈提供「加入生词本」按钮由用户自选
- **不存快照**:自由拼写/听写会话不做断点续学,`saveSessionSnapshot` 只服务学习/复习会话;离开页面会话即弃

### 4.13 听写(2026-08-30)

- **入口**:首页「听写」行动作(`dictationEntry`,**Edge朗读与 speechSynthesis 都不可用的浏览器才隐藏**,守卫 `canSpeakHere()`)→ `screen-dictate` 配置页
- **配置**(存 `settings.dict*`,记住上次选择):作答方式 `dictMode` 三态(**输入判分 judge** / **只听自查 listen** / **自动轮播 auto**)、范围+数量(自定义 1 ~ 词库总词数,含自选词单,见 4.12)、两轮之间停顿(0.5/1/2/3 秒,`dictPause` 默认 1 秒)、播放顺序(顺序/随机,`dictOrder`)、循环播放(`dictLoop`,整轮播完自动重置再来,顶栏「结束」退出)、语速滑杆 0.5~1.5(`dictRate` 默认 0.9);旧存档只有 `dictJudge`(bool) 时在 `loadState` 迁移为三态
- **自动轮播(免手持,2026-08-30)**:单词+释义**全程常显**在卡片上,播放节奏与判分/自查完全一致(两轮,不再额外强化读第三遍,2026-08-30 按用户要求对齐)→ 留白 ≥2 秒 → 自动切下一个词(`playDictCycle` 末尾分支,标 rec.done 后 `dictNext`);无输入框,配循环播放即"戴耳机走路磨耳朵"状态,「结束」随时退出
- **播放节奏**:每个词播**两轮**,每轮 = 英文单词读 2 次 + 汉语释义读 1 次(`zh-CN`),轮间停顿可设;英文 `en-US`、语速跟设置,汉译语速 = 语速+0.1(上限 1);汉译朗读用 `speakableDef()` 剥离**全部**词性标记并清理分隔符(多词性释义如 "adv. 在下面 prep. 在..下面 n. 底部" 只读 "在下面,在..下面,底部")
- **实现**:`playDictCycle` async 链式播报(`speakDictText` 统一入口:Edge 朗读 `edgePlayAwait` 以 `<audio>` `onended` 推进,超时兜底 `max(8s, 字数×900ms)` 防网络慢/事件不触发,失败自动降级设备TTS `speakAwait` 并提示一次;TTS 版以 utterance `onend` 推进,超时兜底 `max(3s, 字数×600ms)`);会话带**代际号 `gen`**,重听/提交/切词/离开页面时 +1,旧播报链检查 `session===sess && sess.gen===gen` 自动作废;全局 `speakEpoch` 保证停止播报(stopDictPlayback)后在途的 Edge 合成不会从降级层冒声;`go()` 离开听写页时调 `stopDictPlayback()` 掐掉在途合成 + 音频 + 取消系统语音队列 + 清锁屏媒体信息。呈现新词时 `prefetchUpcomingAudio()` 预取后面 4 个词(单词+汉译,见 4.5),切词/首听零等待
- **熄屏/切后台续播**(2026-08-30):播报不再走 speechSynthesis(系统会挂起),改走 `<audio>` 真音频流——熄屏/切后台浏览器继续播,锁屏界面显示当前单词(navigator.mediaSession,`updateDictMediaSession`);播过的词音频在 IndexedDB 永久缓存,断网也能续播缓存过的词。局限:降级到设备 TTS 时熄屏仍会暂停(系统限制);从最近任务划掉 App 任何方案都无解
- **音源缓存**(2026-08-30):有道/百度在线音源已移除,SW 的音频拦截(`cet4-audio-v1`)同步删除,旧用户缓存随 SW 换版自动清除;Edge 朗读音频缓存在页面侧 IndexedDB(`cet4-edge-tts`),不经过 SW
- **判分模式**:播放同时可输入提交(提交即停播);答错进重现池(每 3 词穿插重现,答对 1 次完成,同自由拼写)
- **只听自查**:单词+释义**全程常显**在卡片上边听边看,播完后点「下一个」手动切词(不判分、无重现池)
- **纯练习**:同自由拼写,不写学习状态、不计每日目标;答错反馈带「加入生词本」
- **已知边界**:① 熄屏续播依赖 Edge 音源(`<audio>` 真音频流);切到设备 TTS 兜底时(Edge 失败/断网且该词未缓存)iPhone 锁屏/切后台后浏览器会暂停 TTS,无法像播客一样锁屏续播;从最近任务划掉 App 任何方案都无解;② Edge 朗读为非官方接口,依赖服务端 UA 校验,微软若收紧策略可能只对官方客户端开放;失效时自动降级设备TTS 不影响功能(无声环境除外);③ 每个词**首次**合成需联网,之后走 IndexedDB 永久缓存离线可用;预取让"第一次听到"通常也不等网络

## 八、已知边界

1. **手机版不能直接改文件生效**——必须重新打包并重新发送给手机
2. **进度跨设备**靠手动导出/导入;进行中会话(快照)不跨设备
3. **电脑版需连 WiFi + 启动服务器;手机版离线可用但需重新传文件**
4. 答错提示的英译汉反查:已优先跳过当前词;同释义多词时可能提示其同义词(语义上仍正确)
5. **设备TTS 兜底的边界**:speechSynthesis 不可用的环境(微信/QQ 等内置浏览器)还有在线音源兜底,仅剩设备TTS 时才受限;iOS 需静音键未开且媒体音量正常;若手机没装英语 TTS 语音包(设置→语言和输入法→文字转语音)且无在线音源才无发音。安卓 Chrome/微信的 speechSynthesis 通常不认第三方引擎(装讯飞语记等无效);**想要自选男女声,用 Edge 浏览器打开并选「Edge朗读」音源**(晓晓/云希等音色)

### 4.11 安全加固

- **CSP**(index.html meta):`script-src 'self' 'unsafe-inline'`(应用用内联 onclick,必须放行;仍禁外站脚本)、`object-src 'none'`、`base-uri 'none'`、`form-action 'none'`、`connect-src 'self' wss://speech.platform.bing.com`(放行 Edge 朗读的 WebSocket;仍禁其它外连)、`upgrade-insecure-requests`;**单文件版打包时剥离 CSP**(内联合并后 'self' 会锁死自身,见 build-single.js)
- **SW 注册**在独立文件 `pwa-register.js`(defer 加载),不在 head 内联
- **导入进度消毒**:`sanitizeWordRecord()` 只接受预期字段/类型(stage 限 0-5、due 数值、inBook 布尔),历史项只收 ≤64 字符的字符串且必须存在于词库;文件大小上限 10MB(设置页导入处)
- **渲染层**:所有 innerHTML 插值均经 `escapeHtml`;不加载任何第三方资源(CSP 也封死了)
- **GitHub Pages 侧**:https 由 GitHub 强制;服务器安全、TLS 与 DDoS 防护均由 GitHub 托管,本应用无后端、无账号体系,进度数据只存本机 localStorage 不出设备
