## 一、项目概览

**四级词汇通** 是一个纯前端的四级英语背单词应用,零后端、零构建、双击即用。

| 项 | 说明 |
| --- | --- |
| 项目路径 | `D:\英语学习\CET-词汇整理\四级词汇通\` |
| 词汇数据 | 4543 个四级单词(来源:`D:\英语学习\CET-词汇整理\文件_去重合并版.txt`) |
| 技术栈 | 原生 HTML + CSS + JavaScript(无框架、无依赖) |
| 数据存储 | 浏览器 `localStorage` |
| 使用方式 | 电脑本地服务器版 + 手机离线单文件版 |

## 二、文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 界面骨架 + 全部 CSS 样式(所有页面容器、弹窗) |
| `app.js` | 核心逻辑:词汇池、艾宾浩斯调度、状态持久化、出题、统计 |
| `ui.js` | 界面交互:页面切换、答题会话状态机、列表渲染、导出导入 |
| `vocab-data.js` | 词汇数据:`const VOCAB = [ [单词, 释义], ... ]` |
| `server.js` | 本地静态服务器(零依赖,Node 内置 http),手机连同一 WiFi 访问 |
| `启动服务器.bat` | 双击启动 server.js 的批处理(ASCII 编码 + CRLF,勿改编码) |
| `build-single.js` | 打包脚本:把 4 个 JS/HTML 合并成手机单文件版 |
| `四级词汇通_手机版.html` | 打包产物:自包含单文件,发到手机直接浏览器打开 |

### ⚠️ 关键注意(易踩坑)

1. **手机版是打包产物**。改任何代码后必须重跑 `node build-single.js` 才会更新手机版;电脑版改完刷新即生效。
2. **`启动服务器.bat` 必须是 ASCII 编码 + CRLF 行尾**。曾因 UTF-8 + LF 导致无法启动;里面不能用 `chcp 65001`(cmd bug 会乱码)。
3. **vocab-data.js 是生成的**,改词汇用 `文件_去重合并版.txt` 再生成,别手改。
4. 电脑版和手机版各存各的 localStorage,进度互不相通,靠「设置 → 导出/导入进度」同步。

## 三、数据模型

### 3.1 localStorage key

| Key | 内容 |
| --- | --- |
| `cet4_study_state_v1` | 学习状态(见下) |
| `cet4_session_snapshot_v1` | 未完成会话快照(断点续学) |

### 3.2 state 结构 (`cet4_study_state_v1`)

```js
state = {
  settings: { dailyNew: 20, dailyReview: 30 },   // 每日计划
  words: {                                        // 每个单词的学习记录
    [word]: {
      stage: 0~5,        // 0新词, 1-4复习级, 5已掌握(完全记住)
      due: 时间戳,        // 下次复习时间(仅 stage>=1 用;已掌握为 Infinity)
      right: 累计答对,     // 注意:这是"累计答对次数",不是会话内计数
      wrong: 累计答错,
      inBook: 是否在生词本,
      created: 首次学习时间戳,
    }
  },
  today: 'Tue Aug 04 2026',          // 当日字符串,用于跨天重置
  learnedToday: [],                  // 今日新学(跨天清空)
  reviewedToday: [],                 // 今日复习(跨天清空)
  masteredTotal: 0,
  history: {                          // 每日学习记录(持久保留)
    '2026-08-04': { learned: [], reviewed: [], wrongs: [] }
  },
}

// 每日目标
goalInfo() = {
  target,        // settings.dailyNew
  learned,       // learnedToday.length
  remaining,     // max(0, target - learned)
  done,          // learned >= target
  allDone,       // done 且无未学单词(全部学完)
  dueToday,      // 今日到期待复习数
  reviewedToday, // reviewedToday.length
}
```

### 3.3 会话快照结构 (`cet4_session_snapshot_v1`)

断点续学用。每个答题动作后保存,完成/放弃时清除。

```js
snapshot = {
  mode: 'study' | 'review',
  queue: [单词...],          // 本次全部单词
  pending: [单词...],        // 待识别队列(新词,答对一次即过)
  retries: [单词...],        // 答错待重记队列(须答对3次)
  sinceRetry: 0,             // 距上次穿插错词的间隔(每3个新词插1个错词)
  idx: 0,
  correct: 0, wrong: 0,      // 会话内计数
  spellOn: false,            // 是否进入拼写阶段
  phase: 'recognize'|'spell'|'spellAsk',
  records: [[word, { errors, corrects, spellCorrects, done }]],
}
```

## 四、核心算法

### 4.1 艾宾浩斯复习间隔

```js
const INTERVALS = [1, 2, 4, 7, 15];   // 天
const STAGE_MASTERED = 5;
```

- 复习**答对一次升 1 级**,下次复习间隔按 `INTERVALS[stage-1]` 天
- 复习**答错一次降 2 级**(`Math.max(0, stage-2)`)
- 升到 `stage >= 5` 判定「完全记住」,`due = Infinity`,不再出现在复习队列
- 复习答错后 `due` 设为 10 分钟后(当天可再复习)

### 4.2 学习/复习会话三段式流程(学习与复习逻辑一致)

```
第1阶段·识别:
  英译汉出题(看单词选释义),四选一
  答对(新词1次,错词3次达标) → 移除队列
  答错/点不会 → 不卡住,进 retries 错词池,显示反馈后刷新下一个
  穿插规则:每学3个新词穿插重现1个错词;多个错词按序轮转交替,避免同一错词连续出现

第2阶段·拼写询问(可选):
  识别全部完成后,弹窗问「要不要练习拼写?」
  开始拼写 或 跳过直接完成(用户可拒绝)

第3阶段·拼写:
  看释义输入英文单词,连续拼对2次(SPELL_REQUIRED)才算完成
  拼错重置连续正确数
```

### 4.3 答错处理

| 位置 | 处理 |
| --- | --- |
| 识别题答错 | 进 retries 重记池、累计 `wrong`、**不强制进生词本**(用户点按钮自选)、写回 state |
| 点「不会」 | 同答错处理,显示答案 |
| 拼写答错 | 重置拼写连续数、累计 `wrong`、写回 state,反馈含正确拼写+释义 |
| 复习答错 | 额外触发艾宾浩斯降级 |

### 4.4 答错反馈(双语提示)

答错后反馈区显示:
```
❌ 答错了，稍后会再考你
  hello   /   n. 你好       ← 正确答案对照(wrong-pair)
  「n. 你好」的英语是：hello    ← 选错选项的翻译提示(wrong-hint)
[📌 加入生词本]  [下一个 →]
```

- **英译汉**选错中文 → 反查词库提示「X 的英语是:…」
- 点「不会」无选错选项时,不显示该行

### 4.5 每日目标

首页「今日目标」卡片:新学进度条(`learned/target`)、复习到期数、完成状态。

- **目标 = `settings.dailyNew`**(设置页可调)
- **达成判定**:`learnedToday.length >= dailyNew`;若同时无未学单词 → 显示「全部学完🏆」
- **阻断**:今日新学达成后,点「学习新词」进入 `goalDoneHtml()` 完成页,不再开新会话;可去设置调高目标继续
- **提交点**:新词在**识别阶段答对达标**即 `learnWord(word,true)` 记为已学(计入 `learnedToday`);拼写阶段是纯练习,不再重复提交
- **隔天复习**:`learnWord` 设 `due = 现在 + 1 天`,保证新词至少隔一天才进入复习队列

### 4.6 断点续学
- 每个答题动作后 `saveSessionSnapshot()` 存快照
- 首页有未完成会话时显示横幅(`resumeBanner`),点「继续」`resumeSession()` 恢复
- 会话完成/放弃时 `clearSessionSnapshot()`
- 快照**不随**导出/导入同步(跨设备进行中会话不互通)

## 六、UI 设计风格

「学习笔记本」风格,避免模板化的蓝白卡片:

- **配色**:纸感背景 `#F6F0E4` + 墨水蓝 `#1F4E79` + 红笔批注 `#C0442B`
- **字体**:衬线(Georgia/宋体)用于单词、标题、数字;等宽(mono)用于徽章、辅助文字
- **签名元素**:首页右上角堆叠迷你单词卡;词卡顶部 `CET-4` 角标
- **交互动画**:出题上浮、答错抖动、答对变绿
- 响应式:宽屏下四选一选项自动变两列;支持 `prefers-reduced-motion`

CSS 全部在 `index.html` 的 `<style>` 内,变量集中在 `:root`。

## 七、扩展指南(给未来开发)

### 改功能时的标准流程

1. 逻辑层改动在 `app.js`(数据/算法/state)
2. 交互层在 `ui.js`(DOM 渲染、事件、会话状态机)
3. 页面骨架/样式在 `index.html`
4. **跑语法检查**:`node --check app.js` 和 `node --check ui.js`
5. **重新打包手机版**:`node build-single.js`
6. 有逻辑改动时,建议跑真实浏览器测试:`python D:\OpenClaw\temp\cet_e2e.py`(需先启动 `node server.js`)

### 常用扩展点

| 想做什么 | 改哪里 |
| --- | --- |
| 调整每日新学/复习量 | `app.js` 的 `state.settings` + 设置页 |
| 改复习间隔 | `app.js` 的 `INTERVALS` 数组 |
| 改"错词需答对几次" | `ui.js` 的 `RECOG_REQUIRED` |
| 改"错词穿插间隔" | `ui.js` 的 `RETRY_INTERVAL`(答错后穿插计数归零,新词学满 N 个重现错词) |
| 改"错词轮转" | `ui.js` 的 `rotateRetries()`(多个错词交替重现,单个错词尾段连续刷满) |

| 加新题型 | `app.js` 的 `makeQuestion()` + `ui.js` 渲染 |

### 测试方式

## 八、已知边界

1. **手机版不能直接改文件生效**——必须重新打包并重新发送给手机
2. **进度跨设备**靠手动导出/导入;进行中会话(快照)不跨设备
3. 电脑版需连 WiFi + 启动服务器;手机版离线可用但需重新传文件
4. 答错提示的英译汉反查:选项的中文释义串来自词库,能反查到单词;若将来词库出现重复释义,反查可能取第一个匹配
