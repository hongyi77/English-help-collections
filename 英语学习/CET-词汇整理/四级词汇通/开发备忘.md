## Edge 朗读关键实测结论（2026-08-30，排查别绕弯）

- **Sec-MS-GEC token 必须用 float64 运算**：ticks≈1.3e17 超出 2^53，浮点舍入后的值才是服务端期望值；用 BigInt 精确计算得到「教科书正确」的值反而 403。此坑与 Python 官方库 `rany2/edge-tts` 的 drm.py 对拍确认。
- **服务端校验浏览器真实 UA**：须含 `Edg/`（桌面）/`EdgA/`（安卓）/`EdgiOS/`（iOS）且主版本 ≥135（实测 130 被拒、135/138/140/143 放行）。UA 是浏览器自动带的、网页改不了 ⇒ **该音源只在 Edge 浏览器里可用**，其他浏览器 `isEdgeBrowser()` 直接判不可用（UI 隐藏 Edge 选项，运行时自动回落设备TTS）。Origin/Cookie/ConnectionId 均不校验，token/版本走 URL 查询参数。
- CSP `connect-src` 放行 `wss://speech.platform.bing.com`，用页面内 `securitypolicyviolation` 事件实测验证过（对照域名被拦、目标域名放行）。
- 失败回落已真浏览器验证：服务端拒绝 → `edgePlayAwait` 返回 false → 无残留连接 → 链条落到设备TTS。
- 官方音色清单可用 `https://speech.platform.bing.com/consumer/speech/synthesize/readaloud/voices/list?trustedclienttoken=6A5AA1D4EAFF4E9FB37E23D68491D6F4`（带 Edge UA）拉取，`EDGE_VOICES` 的 16 个 ShortName 已全部对照校验过。
- **装讯飞语记等第三方 TTS 引擎对安卓 Chrome/Edge 的 speechSynthesis 无效**（浏览器不暴露第三方引擎声音）——手机上自选男女声只能走 Edge 音源这条路。

## 关键技术事实（排查时别绕弯）

- GitHub Pages 给 sw.js 的 HTTP 缓存 max-age=600，`pwa-register.js` 里 `sw.js?v=N` 的 N 必须和 `sw.js` 的 `CACHE_VER` 同步改，否则换版卡 10 分钟。**v11 起安装/同源刷新都带 `cache:'reload'`**：此前部署窗口期 HTTP 缓存会把旧 index.html 装进新 SW 缓存（旧页面+新 JS 混版，旧 onclick 调不到改名后的函数，症状=设置页点击无反应，2026-08-30 用户真机踩过）。

- Edge 音频缓存在页面侧 IndexedDB，SW 管不到；SW 只管静态资源。别再往 sw.js 里加音频拦截（在线真人音源已删）。
