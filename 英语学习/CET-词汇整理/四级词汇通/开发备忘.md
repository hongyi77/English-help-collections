### Edge 朗读关键实测结论（2026-08-30，排查别绕弯）

- **Sec-MS-GEC token 必须用 float64 运算**：ticks≈1.3e17 超出 2^53，浮点舍入后的值才是服务端期望值；用 BigInt 精确计算得到「教科书正确」的值反而 403。此坑与 Python 官方库 `rany2/edge-tts` 的 drm.py 对拍确认。
- **服务端校验浏览器真实 UA**：须含 `Edg/`（桌面）/`EdgA/`（安卓）/`EdgiOS/`（iOS）且主版本 ≥135（实测 130 被拒、135/138/140/143 放行）。UA 是浏览器自动带的、网页改不了 ⇒ **该音源只在 Edge 浏览器里可用**，其他浏览器 `isEdgeBrowser()` 直接判不可用（UI 隐藏 Edge 选项，运行时自动回落在线真人）。Origin/Cookie/ConnectionId 均不校验，token/版本走 URL 查询参数。
- CSP `connect-src` 已放行 `wss://speech.platform.bing.com`，用页面内 `securitypolicyviolation` 事件实测验证（对照域名被拦、目标域名放行）。
- 失败回落已真浏览器验证：服务端拒绝 → `edgePlayAwait` 返回 false → 无残留连接 → 链条落到有道/百度。
- 官方音色清单可用 `https://speech.platform.bing.com/consumer/speech/synthesize/readaloud/voices/list?trustedclienttoken=6A5AA1D4EAFF4E9FB37E23D68491D6F4`（带 Edge UA）拉取，`EDGE_VOICES` 的 16 个 ShortName 已全部对照校验过。
- **装讯飞语记等第三方 TTS 引擎对安卓 Chrome/Edge 的 speechSynthesis 无效**（浏览器不暴露第三方引擎声音）——手机上自选男女声只能走 Edge 音源这条 路。

## 关键技术事实（排查时别绕弯）

- 有道 `dictvoice` 中文长句不稳定（部分文本 500），汉译必须用百度 `gettts`；两接口均**无 CORS 头**，页面 fetch 不到，播放必须走 `<audio>` 元素，离线靠 SW 缓存（不透明响应整包存整包回）。
- Edge 朗读的坑见上节；三个在线音源里只有 Edge 有音色/性别参数。
- GitHub Pages 给 sw.js 的 HTTP 缓存 max-age=600，`pwa-register.js` 里 `sw.js?v=N` 的 N 必须和 `sw.js` 的 `CACHE_VER` 同步改，否则换版卡 10 分钟。**v11 起安装/同源刷新都带 `cache:'reload'`**：此前部署窗口期 HTTP 缓存会把旧 index.html 装进新 SW 缓存（旧页面+新 JS 混版，旧 onclick 调不到改名后的函数，症状=设置页点击无反应，2026-08-30 用户真机踩过）。
- 手机微信/QQ 等无 speechSynthesis 的浏览器靠在线音源也能用听写（入口守卫 `canSpeakHere()`）。
- 本地测试：`启动服务器.bat`（localhost:8080）；改完代码跑 `node test-logic.js`，改完任何代码要 `node build-single.js` 重打包手机版。
