# English-help-collections

一套面向中国学习者的英语学习工具合集，包含背单词应用与技术英语词库。

## 项目结构

```
English-help-collections/
├── 英语学习/
│   ├── CET-词汇整理/
│   │   └── 四级词汇通/          # 核心应用：多词库背单词 App
│   └── most-frequent-technology-english-words-master/  # 程序员高频技术英语词汇
└── README.md
```

## 📖 英语词汇通

纯前端背单词应用，零后端、零构建、双击即用。支持电脑浏览器与手机 PWA，进度可导出/导入跨设备同步。

### 功能特性

- **多词库**：支持 14 个词库（四六级 / 四六级核心词 / 四六级精简词 / **专升本** / **雅思** / **托福** / 小学 / 初中 / 高中 / 蝶变系列），按系列分组展示；四六级另附「核心词 / 精简词」子库，按历年真题词频精选高频重点词。专升本/雅思/托福词表源自权威词书（新东方·不背单词结构化数据、开源专升本词库项目），全部经 ECDICT 开源权威词典逐词校验
- **艾宾浩斯复习**：科学间隔重复算法，答对升级、答错降级，完全记住后不再出现
- **FSRS 自适应复习（可选）**：按每个词的记忆强度自动安排复习——记得牢的词间隔拉长、容易忘的词早点回来，总复习量更少；目标记忆保持率 85/90/95% 可调，随时切回经典节奏（移植官方 FSRS-6 算法）
- **三段式答题**：识别（四选一）→ 拼写（可选计入：拼错按复习答错处理、拼对不重复计分）；新学答对出绿框确认，复习即答即走；答错后选项原地揭示——正确项与所选项高亮对照，其余干扰项点击展开「单词+释义」
- **新学断点续学**：新学会话中途退出，再点「新学」直接接着上次的队列和位置继续（快照按词库+学习日保存，跨天/切词库自动作废）；整批词过完一遍后拼写环节给出选择——继续拼写或跳过（跳过不再触发、不影响进度），拼写中途退出后再进来仍会询问，永不强制完成
- **多模式练习**：自由拼写 / 听写（判分 / 自查 / 自动轮播）/ 听音辨义（只听发音选释义）/ 快速复习（先自评再翻面校验，可改判「记错了」），范围、数量、按日期、自选词单自由组合，错词自动穿插重现
- **错词重练**：首页一键重练昨天答错的词——专练进度独立展示，不写复习排期，复习与巩固两遍各司其职
- **答题体验**：底部固定继续栏（反馈再长按钮不出屏）、答对/答错提示音效（可关）、选项数字键角标（桌面键盘 1-4 作答）、答题进度条
- **顽固词机制**：复习答错累计 5 次自动标记，可单独查看或专项练习（Anki Leech 思路）
- **智能发音**：双引擎音源——Edge 朗读（男女音色自选，带永久缓存与预取、整库离线包）+ 设备 TTS 兜底，离线可用
- **PWA 支持**：添加到手机主屏幕，全屏独立运行，断网可用；听写/听音辨义熄屏续播
- **深色模式**：跟随系统或手动锁定（浅色 / 深色），原生控件与状态栏颜色联动
- **生词本 & 统计**：生词本按错误次数或添加顺序排序（行内「错 N」徽章）；掌握情况分五级展示并含学习热力图；30 天学习记录按新学/复习/答错筛选；单词列表双行卡片布局
- **每日目标**：新学与复习各自独立设定目标，按词库独立计算进度，**早上 5 点重置**（凌晨学习计入前一天，夜猫子过午夜进度不清零）
- **例句辅助**：10710 词全覆盖四级+专升本词库，每词配英文例句+中文翻译，答对反馈卡/答错揭示/词典页精确命中时展示（词书权威来源 + AI 生成，全部经机器校验）
- **自建词库**：设置页可自建词库——粘贴文本或导入 .txt/.csv（每行一词，可带释义），只写单词的自动从现有词库补释义，查不到的词剔除并列出；支持切换学习（进度独立）、导出、删除（上限 5000 词/库、20 个库，词表独立存储不占学习存档）

### 快速开始

| 平台 | 方式 |
| --- | --- |
| 电脑 | 下载本项目，双击 `启动服务器.bat`，浏览器访问 http://localhost:8080 |
| 手机 | 电脑与手机连同一 WiFi，手机浏览器访问电脑 IP + 端口（如 http://192.168.1.100:8080），然后「添加到主屏幕」 |
| 离线单文件 | 改完代码后运行 `node build-single.js`，将产物发到手机直接打开 |

### 部署到 GitHub Pages

仓库已配置 GitHub Actions，推送到 `main` 分支自动部署。部署后通过以下地址访问：

```
https://<你的用户名>.github.io/<仓库名>/CET-词汇整理/四级词汇通/index.html
```

### 词库数据说明

词库数据由源文件自动生成，**不建议手动编辑生成的 JS 文件**。

| 源文件 | 生成文件 |
| --- | --- |
| `文件_去重合并版.txt`（CET-4 词表） | `vocab-data.js` |
| `lib-sources/*.json` 或 `*.txt` | `vocab-libs.js` |
| `vocab-extra-chunks/*.js` + `hard-words.json` | `vocab-extra.js`（巧记数据） |

新增词库来源：**雅思词汇**（新东方雅思词汇，经不背单词结构化数据，3574 词）、**托福词汇**（新东方 TOEFL 词汇，4263 词）、**专升本词汇**（开源专升本词库项目 xsaddd1/CET-4 整理，5553 词，含音标词性释义）；三者均与 ECDICT（开源权威英汉词典，77 万词条）逐词比对校验，个别 ECDICT 未收录的专有名词（Kung Fu、MasterCard 等）保留自词书原表。

## 📘 程序员英语词汇宝典

来自 [Wei-Xia/most-frequent-technology-english-words](https://github.com/Wei-Xia/most-frequent-technology-english-words) 的程序员高频技术英语词汇表，收录计算机书籍、文档、文章中常见技术词汇。

### 使用方式

- **在线浏览**：[learn-english.dev](https://learn-english.dev/)

### 贡献

发现翻译错误或有更合适的释义？欢迎提交 Pull Request。更新规则：

- 单词文件位于 `_posts/` 目录，按首字母顺序更新
- 单词首字母小写，翻译使用中文标点
